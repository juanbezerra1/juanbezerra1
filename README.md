# Juan Bezerra

MSc student in Biomedical Engineering at COPPE/UFRJ (Brazil), with a BSc in Biophysics. I work with biosignals (EMG, force, EEG) and like turning an analysis into code that is small, tested and reproducible.

*Em português:* Mestrando em Engenharia Biomédica na COPPE/UFRJ, com graduação em Biofísica. Trabalho com biossinais (EMG, força, EEG) e gosto de transformar uma análise em código pequeno, testado e reprodutível.

## Projects

**Signals and machine learning**

| Project | What it does |
|---|---|
| [biosigkit](https://github.com/juanbezerra1/biosigkit) | From raw EMG / EEG / force recordings to a tidy feature table, an honest cross-subject accuracy and a SQL database. |
| [subjectwise-ml](https://github.com/juanbezerra1/subjectwise-ml) | Leakage-free validation, permutation tests and power analysis for classifiers trained on a handful of subjects. |
| [eeg-erds](https://github.com/juanbezerra1/eeg-erds) | ERD/ERS, ERP peaks, SOBI blink removal and epoch rejection for epoched EEG, tested against synthetic recordings whose ground truth is known. |
| [experiment-randomizer](https://github.com/juanbezerra1/experiment-randomizer) | Reproducible, auditable randomisation for small experiments: permuted-block allocation, balanced condition orders and a tamper-evident log. Standard library only. |

**Databases and BI** (an invented biosignal lab, with invented data)

| Project | What it does |
|---|---|
| [labtrack-db](https://github.com/juanbezerra1/labtrack-db) | A PostgreSQL schema whose constraints refuse bad data: migrations, reproducible synthetic data, teaching queries, an EXPLAIN lab and a star schema, tested against a real PostgreSQL. |
| [labtrack-bi](https://github.com/juanbezerra1/labtrack-bi) | A Power BI project kept as text (TMDL, DAX, Power Query), with the numbers the report must show worked out in two independent ways. |

Every project has tests, continuous integration on GitHub Actions, and a README in English and in Portuguese.

Python (NumPy, SciPy, pandas, scikit-learn, Matplotlib), SQL (PostgreSQL, SQLite), Power BI projects as text (TMDL, DAX, Power Query), pytest, ruff, mypy, Docker Compose, Git and GitHub Actions.
